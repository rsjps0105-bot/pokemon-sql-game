# poke-loader 利用ドキュメント

## ポケモンSQLゲーム：データベース初期化・再現手順

------------------------------------------------------------------------

## 1. 目的

本ドキュメントは、ポケモンSQLゲーム用の MySQLデータベースを
**再現・共有するための標準手順** をまとめたものです。

以下の2通りの方法で再現できます：

1.  スキーマ＋importスクリプト方式
2.  ダンプファイル方式（完全復元）

------------------------------------------------------------------------

## 2. 必要環境

-   Node.js（LTS推奨）
-   MySQL 8系

------------------------------------------------------------------------

## 3. フォルダ構成

    pokemon-sql-game/
    ├ poke-loader/
    │   ├ import_pokemon_151.mjs
    │   ├ poke_sql_game.sql
    │   ├ package.json
    │   └ package-lock.json
    ├ .env.example

------------------------------------------------------------------------

# 【方法A】スキーマ＋importスクリプト方式

## A-1 依存関係のインストール

    cd poke-loader
    npm install

------------------------------------------------------------------------

## A-2 データベース作成

``` sql
CREATE DATABASE poke_sql_game
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

------------------------------------------------------------------------

## A-3 環境変数の設定

プロジェクトルートに `.env` を作成。

例：

    DB_HOST=localhost
    DB_USER=root
    DB_PASSWORD=自分のパスワード
    DB_NAME=poke_sql_game
    DB_CHARSET=utf8mb4

------------------------------------------------------------------------

## A-4 スキーマ適用

    mysql -u root -p poke_sql_game < poke-loader/poke_sql_game.sql

------------------------------------------------------------------------

## A-5 ポケモン151匹投入

    cd poke-loader
    node import_pokemon_151.mjs

------------------------------------------------------------------------

# 【方法B】ダンプファイル方式（完全復元）

ダンプファイルには以下が含まれます：

-   CREATE TABLE
-   INSERT INTO

この方式では import スクリプトは不要です。

------------------------------------------------------------------------

## B-1 データベース作成

``` sql
CREATE DATABASE poke_sql_game
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

------------------------------------------------------------------------

## B-2 ダンプ適用

    mysql -u root -p poke_sql_game < poke_sql_game.sql

これだけで完全に同じDB状態が再現されます。

------------------------------------------------------------------------

# ダンプ作成方法（共有用）

文字化け防止のため、以下の方法を推奨します。

    mysqldump -u root -p --default-character-set=utf8mb4 --result-file=poke_sql_game.sql poke_sql_game

PowerShellで `>` を使う方法は日本語が壊れる場合があります。

------------------------------------------------------------------------

# 動作確認

``` sql
SELECT id, name_ja FROM pokemon WHERE id IN (1,4,25);
```

以下が表示されれば成功：

-   フシギダネ
-   ヒトカゲ
-   ピカチュウ

------------------------------------------------------------------------

# まとめ

-   開発向き：方法A（importスクリプト）
-   配布・提出向き：方法B（ダンプ方式）

どちらの方法でも同一データベースを再現できます。
